# Experiments

This repository is a low-stakes engineering lab for trying implementation ideas before promoting mature work into a focused project.

## Experiment lifecycle

```text
Idea → Small implementation → Observe → Test → Document → Promote or discard
```

## Rules

- Keep experiments isolated and small.
- Do not commit secrets or local environment files.
- Record meaningful assumptions and observations.
- Promote useful experiments into dedicated repositories when they become maintainable projects.
- Do not describe an experiment as production-ready without evidence.
